🏥 Patient Records Management System

A Full Stack CRUD Application for managing patients, their medical records, and appointments. Built with Next.js, Node.js, Prisma, and MongoDB, this project demonstrates modern web development practices, secure authentication, and an intuitive UI.

✨ Features

👤 Patient Management – Create, update, delete, and list patients.

📂 Medical Records – Store and view patient medical history.

📅 Appointments – Schedule and manage patient appointments.

🔐 Authentication & Roles – Secure login with role-based access (Admin, Doctor, Nurse).

📊 Dashboard – Overview of patients, appointments, and system statistics.

📧 Notifications – Email/SMS reminders for appointments (Twilio/Resend integration).

🛠️ Tech Stack

Frontend: Next.js
, React
, Tailwind CSS

Backend: Node.js
, Prisma

Database: MongoDB

Auth: NextAuth.js (Google OAuth / Credentials)

Notifications: Twilio (SMS), Resend/Mailjet (Emails)

Deployment: Vercel (Frontend), Railway/Render (Backend), MongoDB Atlas
